# Contributing

Issues and suggestions are welcome across all Post Oak Labs repositories.

- **AINumbers.co** — use the [suggest a tool](https://ainumbers.co/suggest.html) channel, or open an issue on the relevant repo.
- **Everything else** — open an issue with as much context as you can.

## Pull requests

We accept PRs, but please open an issue or start a discussion first for anything beyond a small fix — deterministic-compute repos (kernels, chains, the OpenChainGraph schema) have conformance rules that aren't always obvious from the diff alone, and we'd rather align before you put in the work.

## Code of Conduct

This project follows the [Contributor Covenant](CODE_OF_CONDUCT.md).
