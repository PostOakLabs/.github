# Security Policy

## Scope

This policy covers all Post Oak Labs repositories under this GitHub organization and the live MCP endpoints they deploy (`mcp.ainumbers.co`, `mcp.apexlogics.org`, `mcp.omegacentauri.me`, `anchor.ainumbers.co`).

## Reporting a vulnerability

Email **tim@postoaklabs.com** with a description of the issue, steps to reproduce, and impact. We aim to acknowledge reports promptly and will keep you updated as we investigate and fix.

We do not currently run a bug-bounty program — there is no monetary reward for reports, but we credit reporters (with permission) once a fix ships.

## Disclosure

Please give us reasonable time to address a report before any public disclosure.
